Start by identifying which machine owns the failing resource. Agent processes, projects, MCP
servers, skills, plugins, and terminals run on the Codevisor Server machine even when you are using
them from another device.

When reporting a problem, include the Codevisor app and server versions, the affected machine, and
the relevant server logs. Do not include pairing tokens, API keys, prompts, source code, or other
credentials.
