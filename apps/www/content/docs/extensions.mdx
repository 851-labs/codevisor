Codevisor has two extension systems: plugins and skills. Both run on the machine that hosts
Codevisor Server.

| Use this | When you need to add                                    | Runtime                                        |
| -------- | ------------------------------------------------------- | ---------------------------------------------- |
| Plugin   | Agent tools, events, inline UI, workspace panes, or all | MCP server over stdio or Streamable HTTP       |
| Skill    | Reusable agent instructions                             | Files installed into harness skill directories |

Every MCP server you add is a plugin, and a plugin can ship its own skills. The server owns plugin
processes, configuration, and connections; connected clients manage them through the HTTP API.
Installed plugins, their accounts, and your skills sync to every Mac signed in to your account.

<Callout type="warning" title="Trust boundary">
  Local plugins and skills can execute code or influence an agent on the server machine. Inspect
  their source and commands before installing them.
</Callout>
