title: Network security
description: Deploy the server without exposing its credentials or transport.

Codevisor apps reach a machine through your Codevisor account: traffic between the app and the
machine is end-to-end encrypted, and the machine only makes outbound connections to Codevisor Cloud.
Signing a machine out with `codevisor auth logout` removes it from your account and revokes its
credential.

The server's own HTTP API speaks plain HTTP and WebSocket and does not terminate TLS. If scripts or
custom clients call it from another host, put it behind a TLS-terminating reverse proxy or a private
overlay network.

## Recommended baseline

- Run with `--auth token` whenever the bind address is not loopback.
- Restrict the server's port (`49361` by default, or the pinned `--port`) with a host firewall or
  private network policy.
- Terminate HTTPS and WSS before traffic crosses an untrusted network.
- Keep the SQLite database and installation directory readable only by the service user.
- Store bearer tokens in an operating-system credential manager.
- Rotate the stable connection token with `codevisor token --rotate` if it is exposed. Separately
  issued tokens have no individual revocation endpoint.
- Remove machines you no longer use from your account with `codevisor auth logout` on the machine,
  or from the machine list in the Codevisor app.

## Extension trust

A local plugin runs its command on every Mac that uses it, and that command can run arbitrary local
code. Skills, including those a plugin ships, can direct an agent to execute tools and change files.
Review the source, command, and requested tools before adding any of them to a sensitive machine.

MCP credentials are encrypted with a key stored in the server data directory, but a process running
as the service user can still access Codevisor's files. Filesystem permissions remain the primary
local boundary.

Plugin accounts keep their tokens and secrets in the shared credential vault. A plugin receives only
the current access token and field values for the request it handles, never a refresh token.

Plugin panes and inline apps load through short-lived view URLs that sandbox the plugin's UI in an
iframe. Never give a plugin webview the machine bearer token.

The hosted API reference intentionally does not execute requests. This prevents server addresses and
bearer tokens from being sent to `www.codevisor.dev`.
